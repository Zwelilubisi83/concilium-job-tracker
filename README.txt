CONCILIUM JOB TRACKER (ONLINE VERSION)

Upload these 5 files to a GitHub repository with GitHub Pages turned on:
index.html, staff.html, style.css, script.js, jobs.js
(Do not upload README.txt.)

Customer page: https://USERNAME.github.io/REPOSITORY/
Staff page:    https://USERNAME.github.io/REPOSITORY/staff.html

On the staff page, fill in your GitHub username, repository name and token once.
After that, every change is published automatically (customers see it in about a minute).
The job list is public. Do not enter customer names or private details.
